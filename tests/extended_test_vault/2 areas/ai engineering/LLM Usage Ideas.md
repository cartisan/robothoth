## Coding
- Create reusable skills for routine maintenance tasks.
- Give a local analysis tool a command-line interface so its checks can be repeated.

## Knowledge management
- Allow an assistant to read most notes and edit designated meeting notes.
- A scheduled task can retrieve authorized meeting transcripts into source notes.
- Review source notes before extracting permanent knowledge.
