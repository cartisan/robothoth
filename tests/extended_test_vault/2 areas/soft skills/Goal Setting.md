## Structure
1. Outcome Oriented Goals: 
	- Define status you want to achieve
	- "Where do I want to be when the goal is done?"
2. Output Oriented Goals
	- Measurable result I'd like to achieve
	- "What result do I want to achieve at the end?"
3. Input Oriented Goals
	- Steps that lead to the achievable result
	- "What is my current theory on achieving my goal"

## Approach
- Environment changes, so input oriented goals might need to be adapted, but output and outcome oriented goal stay the same 
### Formulating outcome oriented goals
- 3-6 months
- Describes a goal state, can be evaluated with yes/no
- No evergreen phrases like: improve, increase, reduce...
- Test questions when done:
	- Does the goal express what you wanted to achieve?
	- Are you satisfied when you achieve exactly what you have formulated in the goal and nothing more?
	- What can we learn from this if the goal was not achieved in the end?
### Formulating output oriented goals
- 1-3 months
- Describes a measurable outcome that generates a benefit
- Address the biggest drivers that pay into the overarching goal
- Test questions when done:
	- Which drivers of success were identified?
	- Does the outcome increase the likelihood of the higher-level goal occurring?
	- Can the result be measured or evaluated at the end with a manageable effort?
	- How confident are you that the overall goal will be achieved with the outputs identified?
### Formulating input oriented goals
- < 1 month
- Best current theory on steps that need to be completed to achieve a goal
- Is adaptable, open to new approaches upon reconsideration
