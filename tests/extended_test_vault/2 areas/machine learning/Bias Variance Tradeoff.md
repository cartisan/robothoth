- both are types of prediction error
- model can rarely minimize both at the same time
- high bias and low variance means *underfitting*
	- model is to simple to capture underlying patterns in data
	- model predicts the same value no matter what input
- high variance and low bias means *overfitting*
	- model is to complex and learns 1:1 mappings instead of underlying patterns in data
	- does not generalize and predictions vary a lot based on each input


## Bias
- average difference between model prediction and true value
- high bias results in high errors on both training and test data

## Variance
- variability or spread of model predictions
- high variance means model does not generalize well
