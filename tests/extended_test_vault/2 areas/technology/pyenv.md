## summary
pyenv works by inserting a directory of shims at the front of your PATH. A shim is a small library that intercepts and changes calls to another library.

## commands
`pyenv install -l`   list all available python versions
`pyenv install 3.7.7`  install a new python with version 3.7.7
`pyenv global 3.7.7` set global python version
`pyenv version` check activy python version
