## summary
- `pyvenv-activate.sh` is a POSIX shell script containing functions to manually or automatically activate and deactivate the Python virtual environment of projects within the current shell.
- In order to load the different environments, [Pipenv](https://github.com/pypa/pipenv) or [Poetry](https://github.com/python-poetry/poetry) must be installed first.
